## How to setting
### 1. Install python3.
You can download any version of python on [here](https://www.python.org/downloads/).

### 2. Create a virtual environment.
```
python -m venv svenv
source svenv/bin/activate
```
You may use any other name instead of ``svenv``.

### 3. Install packages.
```
pip install -r requirements.txt
```

You can find more detailed process in [Lecture 1 Slide](https://github.com/nyeoglya/cs101-smp/blob/main/ppt/lec1.pdf).
